# Exercise 0.6: New note in Single Page App

```mermaid
sequenceDiagram
    participant browser
    participant server

    Note right of browser: User writes a note and clicks Save

    Note right of browser: JavaScript prevents the default form submission

    browser->>server: POST /exampleapp/new_note_spa
    Note right of browser: Request body contains the note content as JSON

    activate server
    Note left of server: Server saves the new note
    server-->>browser: HTTP 201 Created
    deactivate server

    Note right of browser: JavaScript updates the notes list in the DOM

    Note right of browser: The page is not reloaded
```
